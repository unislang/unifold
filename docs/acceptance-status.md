# 1.0 acceptance status

This is the concise implementation register for the 34 criteria in the
[architecture plan](../ARCHITECTURE_IMPLEMENTATION_PLAN.md#acceptance-criteria-for-10). It records
evidence present in the repository, not an assertion that every cited suite was rerun in this
documentation change.

Statuses have deliberately strict meanings:

- **Proved**: direct evidence covers the whole criterion. AC4, AC27, AC33, and AC34 currently meet this
  bar.
- **Partial**: useful implementation or tests exist, but at least one required case or environment
  is unproved.
- **Missing**: the criterion's defining evidence does not yet exist.
- **Contradicted**: current behavior is known to violate the criterion. No row has this status now;
  AC34's earlier semantic-publication contradiction is fixed and its broader isolation contract is
  now proved by application, Studio-browser, and benchmark evidence.
